## NOTES FOR WORDPRESS MIGRATION

1. **Language Keys**: Each translatable element has a unique key. These are stored in `translations.json` for the static site. In WordPress, use Polylang or WPML to handle translations.

2. **Images**: Replace all placeholder images with actual project images from your portfolio.

3. **Colors**: Primary color is #0066cc, accent is #ff6b35. Configure these in WordPress theme customizer or through CSS.

4. **Responsive Design**: WordPress will handle responsiveness through your theme. Ensure chosen theme is mobile-friendly.

5. **SEO**: Update all pages with relevant keywords and meta descriptions in Yoast SEO.

6. **Forms**: Contact Form 7 is the recommended plugin for handling forms in WordPress.

7. **RTL Support**: For Arabic language, ensure your WordPress theme supports RTL. Polylang handles this automatically.
